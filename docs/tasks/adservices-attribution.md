# TASK: AdServices — атрибуция установок из Apple Search Ads

**Приоритет: средний. Нужно ДО масштабирования рекламного бюджета, не блокирует старт рекламы.**

## Зачем

Запускаем Apple Search Ads. Без фреймворка AdServices консоль ASA покажет установки и CPI
(Apple считает показ→тап→установка сама), но мы **не сможем связать установку с тем, что было
дальше** — оформил ли человек подписку, дошёл ли до первой записи. То есть будем оптимизировать
дешёвые установки вместо доходных.

## Что сделать

1. Добавить в проект фреймворк **AdServices** (`import AdServices`, iOS 14.3+ — наш минимум 17.0,
   так что доступен без условий).
2. При первом запуске получить токен атрибуции:
   ```swift
   let token = try AAAttribution.attributionToken()
   ```
   Вызов синхронный и может бросать — оборачивать в do/catch, отсутствие токена это норма
   (органическая установка, не-ASA трафик).
3. Отправить токен на `https://api-adservices.apple.com/api/v1/` (POST, тело — сам токен,
   `Content-Type: text/plain`). Ответ — JSON с `campaignId`, `keywordId`, `adGroupId`,
   `attribution: true/false`.
4. **Где хранить результат — вопрос архитектурный, и тут есть ограничение:** у приложения нет
   бэкенда и privacy-лейбл «Data Not Collected». Отправлять атрибуцию куда-либо наружу — значит
   перезаполнять лейбл и править privacy policy, чего делать не хотим.

   Предлагаемое решение: сохранять ответ **локально** (UserDefaults/SwiftData) и использовать
   внутри приложения — например, помечать когорту пользователя, чтобы потом сопоставить с
   подписками в отчётах ASC вручную. Токен наружу уходит только в Apple, а это не сбор данных
   третьей стороной.

   Если этого мало для нормальной аналитики — обсудить отдельно, потому что альтернатива
   (свой сервер или SDK) ломает позиционирование «никакого трекинга». **Не принимай это решение
   в одиночку, вынеси владельцу.**

5. Токен запрашивается один раз, результат кэшировать. Повторные вызовы API Apple лимитирует.

## Проверка

- Органическая установка: `attributionToken()` не бросает, ответ приходит с `attribution: false`.
- Сборка проходит с включённым AdServices на устройстве (в симуляторе токен недоступен).
- Privacy-лейбл НЕ меняется: убедиться, что никакие данные не уходят никуда, кроме
  `api-adservices.apple.com`.
