# Как выложить Nenita в App Store Connect и TestFlight

Пошагово, от нуля до сборки, которую можно поставить себе на телефон.

---

## ⚠️ Шаг 0. Решить про bundle ID — до того, как создавать приложение

**Это единственный шаг, который нельзя отменить.** Bundle ID намертво привязывается к записи приложения в App Store Connect. Поменять его потом невозможно: придётся заводить новую запись и терять отзывы, рейтинг и историю загрузок.

Сейчас в проекте:

| Что | Значение | Файл |
|-----|----------|------|
| Bundle ID | `com.babybloom.app` | `project.yml` → `PRODUCT_BUNDLE_IDENTIFIER` |
| App Group | `group.com.babybloom.app` | `project.yml` → entitlements обоих таргетов |
| iCloud-контейнер | `iCloud.com.babybloom.app` | `project.yml` → entitlements |
| Bundle ID виджета | `com.babybloom.app.widget` | `project.yml` |

Приложение теперь называется Nenita, а идентификаторы остались от BabyBloom. Пользователь их не видит никогда — они всплывают только в консоли разработчика. Но если хочется чистоты, менять надо **сейчас**, до создания записи в ASC.

Смена App Group и iCloud-контейнера стирает локальные данные и данные в CloudKit — до публикации это ничего не стоит, после публикации это потеря данных у всех пользователей.

Bundle ID не обязан совпадать с именем приложения. `com.babybloom.app` с именем Nenita — рабочая, ничем не грозящая ситуация.

## Шаг 1. Аккаунт разработчика

1. Нужен Apple Developer Program — 99 $ в год, [developer.apple.com/programs](https://developer.apple.com/programs/).
2. Регистрация как физлицо или как компания. Физлицо проще (нужен только Apple ID и карта), но имя разработчика в сторе будет вашим настоящим именем. Для компании нужен D-U-N-S номер и это занимает недели.
3. Активация обычно занимает от пары часов до двух суток.

---

## Шаг 2. Зарегистрировать идентификаторы

В [developer.apple.com/account](https://developer.apple.com/account) → **Certificates, Identifiers & Profiles**:

1. **Identifiers → App IDs → +** → App → bundle ID приложения. Включить возможности: **App Groups**, **iCloud (CloudKit)**, **Push Notifications** (нужны для CloudKit-синхронизации).
2. Ещё один App ID для виджета: `<bundle-id>.widget`, включить **App Groups**.
3. **Identifiers → App Groups → +** → создать группу с тем же идентификатором, что в `project.yml`.
4. **Identifiers → iCloud Containers → +** → создать контейнер, привязать к обоим App ID.

---

## Шаг 3. Прописать команду в проекте

В `project.yml` у обоих таргетов сейчас пусто:

```yaml
DEVELOPMENT_TEAM: ""
```

Вписать свой Team ID (10 символов, виден в аккаунте разработчика в правом верхнем углу), затем перегенерировать проект:

```bash
xcodegen generate
```

Подпись стоит `CODE_SIGN_STYLE: Automatic` — Xcode выпустит сертификаты и профили сам, ничего вручную создавать не надо.

## Шаг 4. Закрыть обязательное перед загрузкой

Это блокеры: без них загрузка либо не пройдёт, либо приложение развернут на ревью.

- **`PrivacyInfo.xcprivacy`** — обязателен с 2024 года. Приложение использует `UserDefaults`, а это API «требующее обоснования»: нужно объявить причину `CA92.1`. Файла в проекте пока нет.
- **Иконка** — уже есть (`AppIcon`), 1024×1024 без прозрачности и без скруглений.
- **Версия и билд** — `MARKETING_VERSION` (например `1.0`) и `CURRENT_PROJECT_VERSION` (целое число). Каждая загрузка в ASC требует **нового номера билда**, даже если версия та же.
- **Скриншоты** — минимум для 6.9" iPhone. Их можно снять на симуляторе.

## Шаг 5. Создать запись приложения в App Store Connect

1. [appstoreconnect.apple.com](https://appstoreconnect.apple.com) → **Мои приложения** → **+** → **Новое приложение**.
2. Платформа iOS, **Имя** — `Nenita` (это и есть резервирование имени; если оно занято, ASC скажет сразу — это и есть настоящая проверка на коллизию, никакой веб-поиск её не заменяет).
3. Основной язык — английский. **Bundle ID** — выбрать из списка тот, что зарегистрировали.
4. **SKU** — любой внутренний код, пользователи его не видят, например `nenita-ios-001`.
5. После создания: **Локализации** → добавить русскую, в ней имя приложения `Ночка`. Так работает двойной бренд.

## Шаг 6. Собрать и загрузить

```bash
xcodegen generate
open BabyBloom.xcodeproj
```

В Xcode:

1. Сверху выбрать устройство **Any iOS Device (arm64)** — не симулятор, иначе пункт Archive будет неактивен.
2. **Product → Archive**. Соберётся релизная сборка, откроется Organizer.
3. **Distribute App** → **App Store Connect** → **Upload**.
4. Подпись — **Automatically manage signing**.
5. После загрузки Apple 5–30 минут обрабатывает билд. Придёт письмо, если что-то не так.

Если Archive падает на подписи — проверьте, что Team ID прописан у **обоих** таргетов и что App Group зарегистрирована в консоли.

## Шаг 7. TestFlight

В ASC → ваше приложение → вкладка **TestFlight**.

**Ответить про экспортное соответствие.** У билда появится статус «Missing Compliance». Нажать на него и ответить на вопрос про шифрование. Приложение не использует нестандартное шифрование — ответ **Нет**. Чтобы не отвечать каждый раз, можно добавить в `Info.plist`:

```xml
<key>ITSAppUsesNonExemptEncryption</key>
<false/>
```

**Внутренние тестировщики** — до 100 человек, каждому нужна роль в вашей команде ASC. **Ревью не требуется**, билд доступен через пару минут. Это то, что нужно, чтобы поставить приложение себе.

1. TestFlight → **Внутренняя группа** → добавить тестировщиков по Apple ID.
2. Назначить группе билд.
3. Тестировщик ставит на телефон приложение **TestFlight** из App Store, входит под своим Apple ID и видит приглашение.

**Внешние тестировщики** — до 10 000 человек по публичной ссылке, но первый билд проходит **Beta App Review** (обычно от суток). Нужны описание для тестировщиков и контактный email.

Билд в TestFlight живёт **90 дней**, потом истекает.

---

## Порядок действий одним списком

1. Решить про bundle ID — **до создания записи в ASC**
2. Оплатить Apple Developer Program
3. Зарегистрировать App ID, App Group, iCloud-контейнер
4. Вписать `DEVELOPMENT_TEAM` в `project.yml`, `xcodegen generate`
5. Добавить `PrivacyInfo.xcprivacy`, проставить версию и билд
6. Создать приложение в ASC, добавить русскую локализацию с именем «Ночка»
7. Archive → Distribute → Upload
8. Ответить про экспортное соответствие
9. Добавить себя во внутреннюю группу TestFlight, назначить билд
