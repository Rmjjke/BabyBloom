# BabyBloom — Push-уведомления

Все уведомления реализованы через `UNUserNotificationCenter` (локальные пуши, не требуют сервера).  
Файл: `BabyBloom/Services/NotificationManager.swift`

---

## Разрешение на отправку

| Когда запрашивается | Место в коде |
|---|---|
| После завершения онбординга | `BabyBloomApp.swift` → `OnboardingView.onComplete` |

Запрашиваются права: `.alert`, `.sound`, `.badge`.

## Уведомления

### 1. Напоминание о кормлении
| Параметр | Значение |
|---|---|
| **ID** | `bb.feeding.reminder` |
| **Заголовок** | "Время кормления 🍼" |
| **Текст** | "Малыш не кормился около 3 часов. Не забудьте зафиксировать кормление." |
| **Задержка** | 3 часа |
| **Когда планируется** | После каждой записи кормления (быстрый старт ГВ, сохранение в AddFeedingSheet, остановка таймера ГВ) |
| **Отменяется** | Автоматически при планировании следующего (т.е. при новой записи кормления) |
| **Файлы** | `FeedingView.swift` → `quickStart()`, `stopFeeding()`, `AddFeedingSheet.save()` |

---

### 2. Предупреждение о долгом кормлении (таймер ГВ)
| Параметр | Значение |
|---|---|
| **ID** | `bb.feeding.active` |
| **Заголовок** | "Кормление идёт долго ⏱" |
| **Текст** | "Кормление продолжается уже 40 минут. Всё в порядке?" |
| **Задержка** | 40 минут |
| **Когда планируется** | При запуске таймера грудного вскармливания (`quickStart(.breast)` или `AddFeedingSheet` с включённым таймером) |
| **Когда отменяется** | При нажатии «Завершить» (остановка таймера в `stopFeeding()`) |
| **Файлы** | `FeedingView.swift` → `quickStart()`, `stopFeeding()`, `AddFeedingSheet.save()` |

---

### 3. Напоминание о сне
| Параметр | Значение |
|---|---|
| **ID** | `bb.sleep.reminder` |
| **Заголовок** | "Пора поспать 😴" |
| **Текст** | "Малыш не спал уже 4 часа. Возможно, пора укладывать." |
| **Задержка** | 4 часа |
| **Когда планируется** | После завершения сна (`stopSleep()`) или сохранения ручной записи (`AddSleepSheet.save()`) |
| **Отменяется** | Автоматически при планировании следующего |
| **Файлы** | `SleepView.swift` → `stopSleep()`, `AddSleepSheet.save()` |

---

### 4. Напоминание о завершении сна (активный таймер)
| Параметр | Значение |
|---|---|
| **ID** | `bb.sleep.active` |
| **Заголовок** | "Малыш ещё спит?" |
| **Текст** | "Не забудьте нажать «Проснулся», когда малыш проснётся." |
| **Задержка** | 3 часа (дневной сон) / 10 часов (ночной сон) |
| **Когда планируется** | При запуске таймера сна (`startSleep()`) |
| **Когда отменяется** | При нажатии «Проснулся» (`stopSleep()`) |
| **Файлы** | `SleepView.swift` → `startSleep()`, `stopSleep()` |

---

## Схема работы

```
Пользователь нажимает "ГВ" (быстрый старт)
  → создаётся FeedingEntry с isActive = true
  → планируется "bb.feeding.reminder" через 3 ч
  → планируется "bb.feeding.active" через 40 мин

Пользователь нажимает "Завершить" (таймер)
  → отменяется "bb.feeding.active"
  → отменяется старый "bb.feeding.reminder"
  → планируется новый "bb.feeding.reminder" через 3 ч

Пользователь нажимает "Дневной сон" или "Ночной сон"
  → создаётся SleepEntry с isActive = true
  → планируется "bb.sleep.active" через 3 ч (или 10 ч для ночного)

Пользователь нажимает "Проснулся"
  → отменяется "bb.sleep.active"
  → планируется "bb.sleep.reminder" через 4 ч
```

## Тексты уведомлений (обе локали)

| Ключ | Русский | Английский |
|---|---|---|
| `notification.feeding_title` | Время кормления 🍼 | Feeding Time 🍼 |
| `notification.feeding_body` | Малыш не кормился около 3 часов… | Your baby hasn't fed in about 3 hours… |
| `notification.feeding_long_title` | Кормление идёт долго ⏱ | Long Feeding Session ⏱ |
| `notification.feeding_long_body` | Кормление продолжается уже 40 минут… | The feeding session has been going for 40 minutes… |
| `notification.sleep_title` | Пора поспать 😴 | Nap Time 😴 |
| `notification.sleep_body` | Малыш не спал уже 4 часа… | Baby hasn't slept for 4 hours… |
| `notification.sleep_active_title` | Малыш ещё спит? | Still sleeping? |
| `notification.sleep_active_body` | Не забудьте нажать «Проснулся»… | Don't forget to tap 'Woke Up'… |

Ключи добавлены в `en.json` и `ru.json`.

## Возможные улучшения (не реализовано)

- **Утреннее напоминание** — ежедневный пуш в 8:00, если за сегодня нет ни одной записи. Реализуется через `UNCalendarNotificationTrigger` с повтором.
- **Настройка интервалов** — экран "Настроить напоминания" в Settings уже есть в навигации (`settings.reminders`), там можно добавить пикеры для изменения задержек (сейчас захардкожены: кормление 3 ч, сон 4 ч, таймер ГВ 40 мин).
- **Уведомления о подгузниках** — по аналогии, если давно нет записей.
- **Badge** — можно показывать счётчик пропущенных записей на иконке приложения.
